# Security Policy

## Supported Versions

We only support the latest release of GDrive Database for security updates. Please make sure you are running the most up-to-date version.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within GDrive Database, please do **NOT** open a public issue. Instead, report it privately so we can address it responsibly.

You can report security vulnerabilities by emailing the repository owner or by opening a private draft security advisory on GitHub.

When reporting, please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue (proof-of-concept code is highly appreciated).
- Any potential impact on users or data.

We will work to acknowledge your report quickly and coordinate a security fix and disclosure release.
